INTERAKTIF BERSAMA FPIB

Portal booth yang menghimpunkan tiga game:
1. Arabic Chess
2. Misi Mencari Hikmah
3. Sirah Journey

CARA MULA — MAC
Double-click START-BOOTH.command. Terminal akan dibuka dan pelayar akan menuju ke portal secara automatik.

CARA MULA — MANUAL
1. Buka Terminal dalam folder ini.
2. Jalankan: python3 serve.py
3. Buka http://localhost:8088

PENTING UNTUK BOOTH
- Jalankan portal sekali dengan internet sebelum acara sehingga footer memaparkan “SEMUA GAME SEDIA OFFLINE”.
- Selepas itu, semua game boleh digunakan tanpa internet pada pelayar dan alamat yang sama.
- Jangan buka index.html secara double-click kerana mod offline dan PWA memerlukan pelayan tempatan.
- Tekan butang KEMBALI pada bar hijau di atas game untuk memilih game lain.
- Butang RESET memuat semula game semasa. Butang SKRIN PENUH sesuai untuk paparan booth.

Logo rasmi KIAS digunakan daripada aset tempatan pengguna. Semua data game, font dan aset berada di dalam folder ini; tiada CDN atau API diperlukan semasa bermain.
