METHOD AND LIMITATIONS
Functional checks run against app.js in Node VM with a simulated DOM, clock,
localStorage and service worker/cache environment. Shipping source is unchanged
by test instrumentation. Static checks cover references, PNG dimensions,
manifest, RTL attributes and CSS breakpoints. JavaScript syntax checked with Node.

These are NOT real-browser/end-to-end tests. Actual Chrome/Edge installation,
mobile visual rendering, Arabic font appearance, physical touchscreen, browser
cache eviction and OS double-click launch were not exercised in this environment.
The available Sites preview does not support this plain static project.
Windows/Mac launch scripts were inspected; Python server syntax checked.
Before booth use, open the ZIP on the actual device, complete one game, wait for
Sedia offline, install if offered, and verify launch once with internet off.
